# کمینگا (Kaminga)

اپ اندروید برای کشف و مطالعه‌ی کمیک، مانگا، مانهوا و وب‌تون به زبان فارسی.
شعار: «دنیای کمیک، مانگا و مانهوا»

- شناسه‌ی برنامه: `com.kaminga.reader`
- Kotlin + Jetpack Compose + MVVM + Navigation Compose
- حداقل اندروید: 7.0 (API 24). Compose از API 21 پشتیبانی می‌کند؛ 24 انتخاب شده تا بدون زحمت اضافه، تقریباً همه‌ی گوشی‌های فعال را پوشش دهد.
- Java/Kotlin: 17 • AGP 8.7.3 • Kotlin 2.0.21 • Gradle 8.9 • compileSdk 35

## وضعیت فعلی: مرحله‌ی ۱ (نسخه‌ی پایه)

> **این نسخه هنوز روی GitHub Actions ساخته و تست نشده است.**
> کد در محیط نوشتن، کامپایل نشده (Android SDK و Gradle در دسترس نبود). اولین اجرای Actions ممکن است خطای ساخت بدهد؛ متن خطا را بفرست تا درست شود.

### چه چیزهایی نوشته شده

- صفحه‌ی خانه: هدر برند، میان‌بر جست‌وجو، بنر، آثار منتخب، تازه‌ترین‌ها، محبوب‌ترین‌ها
- کشف آثار: جست‌وجوی محلی (نام، نویسنده، هنرمند، ژانر، نوع)، فیلتر نوع/ژانر/وضعیت/زبان، مرتب‌سازی، پاک کردن فیلترها، حالت «نتیجه‌ای نیست»
- جزئیات اثر: جلد، نام فارسی و اصلی، خلاصه، ژانرها، نویسنده/هنرمند، وضعیت، زبان، فهرست فصل‌ها، حالت «بدون فصل»
- کتابخانه‌ی من: فقط حالت خالی / وارد نشده
- ناوبری واقعی (نوار پایین + صفحه‌ی جزئیات)، حالت‌های بارگذاری، خطا (با تلاش دوباره)، خالی
- داده از مخزن (`ComicRepository`) خوانده می‌شود، نه از داخل صفحه‌ها
- ۴ فایل تست JUnit برای جست‌وجو، مخزن نمایشی و ViewModelها
- ورک‌فلو GitHub Actions: بررسی ساختار → تست → APK دیباگ

### چه چیزهایی هنوز نیست

مطالعه‌گر و صفحه‌های واقعی کمیک، علاقه‌مندی‌ها و تاریخچه (ذخیره‌ی محلی)، حساب کاربری و ورود با پیامک، بک‌اند، پنل مدیریت، امتیاز و دیدگاه، ارسال اثر توسط کاربر، دانلود آفلاین، تصویر جلد واقعی، متن‌های انگلیسی رابط (فعلاً رابط فارسی و همیشه راست‌به‌چپ است)، تست رابط کاربری (androidTest)، امضای نسخه‌ی انتشار.

### داده‌ی نمایشی

هشت اثر کاملاً ساختگی (نام، نویسنده و داستان خیالی، بدون تصویر کپی‌رایتی) در `data/demo/DemoData.kt` هستند و همه برچسب «DEMO / نمایشی» می‌گیرند. جلدها گرادیان رنگی‌اند، نه تصویر.

## ساخت APK از روی گوشی

1. در GitHub یک مخزن بساز (یا از مخزن `Kaminga` فعلی استفاده کن).
2. **محتوای** همین پوشه را (نه خود فایل ZIP را) در ریشه‌ی مخزن آپلود کن. اگر فایل‌های قبلی هست، قبل از جایگزینی مطمئن شو چیزی لازم نداری.
3. تب **Actions** را باز کن؛ اگر خواست، Actions را فعال کن.
4. **Build Android APK** را انتخاب و **Run workflow** را بزن (یا یک commit به `main` بفرست).
5. صبر کن تا اجرا تمام شود. مرحله‌ها: بررسی ساختار، تست، ساخت APK.
6. از پایین صفحه‌ی اجرا، artifact با نام **Kaminga-debug-apk** را دانلود کن، ZIP را باز کن و `app-debug.apk` را نصب کن (نصب از منبع ناشناس باید برای مرورگر یا فایل‌منیجر مجاز باشد).
7. اگر اجرا قرمز شد: وارد مرحله‌ی قرمز شو، آخرین ۳۰–۴۰ خط خطا را کپی کن و بفرست. گزارش تست‌ها هم در artifact به نام **Kaminga-unit-test-reports** هست.

نکته: این مخزن Gradle wrapper ندارد؛ ورک‌فلو خودش Gradle 8.9 را نصب می‌کند. برای ساخت محلی با Android Studio، یک بار «Sync» کافی است.

## ساختار

```
app/src/main/java/com/kaminga/reader/
  MainActivity.kt, KamingaApp.kt
  navigation/        مسیرها و تب‌های پایین
  core/common/       UiState، ساخت ViewModel
  core/designsystem/ کامپوننت‌های مشترک (کارت، جلد، حالت‌های خالی/خطا)
  domain/            مدل‌ها، رابط مخزن، منطق جست‌وجو (بدون وابستگی به اندروید)
  data/              مخزن نمایشی و داده‌ی Demo
  di/                AppContainer
  feature/           home، search، details، library
  ui/theme/          رنگ و تم
app/src/test/        تست‌های واحد
docs/architecture.md
```

## امنیت و محتوا

هیچ کلید، رمز یا سرویس پولی در پروژه نیست. فقط محتوایی را منتشر کن که مالکش هستی یا مجوز داری. برای ورود با پیامک، بک‌اند و پنل مدیریت، قبل از شروع محدودیت‌های سرویس‌ها (هزینه، کارت بانکی، دسترسی از ایران) جداگانه بررسی می‌شود.
