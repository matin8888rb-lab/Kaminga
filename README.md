# کمینگا (Kaminga)

اپ اندروید برای کشف و مطالعه‌ی کمیک، مانگا، مانهوا و وب‌تون به زبان فارسی.
شعار: «دنیای کمیک، مانگا و مانهوا»

- شناسه‌ی برنامه: `com.kaminga.reader`
- Kotlin + Jetpack Compose + MVVM + Navigation Compose + DataStore
- حداقل اندروید: 7.0 (API 24)
- Java/Kotlin: 17 • AGP 8.7.3 • Kotlin 2.0.21 • Gradle 8.9 • compileSdk 35

## وضعیت فعلی: مرحله‌ی ۲ (مطالعه‌گر و کتابخانه‌ی شخصی)

> مرحله‌ی ۱ روی GitHub Actions ساخته و روی گوشی تست شد. **کد مرحله‌ی ۲ هنوز ساخته و اجرا نشده است.**
> اگر اجرای Actions قرمز شد، متن خطا را بفرست تا درست شود.

### چه چیزهایی کار می‌کند (طبق کد؛ منتظر تست روی گوشی)

- **مطالعه‌گر** با دو حالت: عمودی (برای وب‌تون و مانهوا) و صفحه‌به‌صفحه (برای کمیک و مانگا)
  - جهت ورق زدن: راست‌به‌چپ یا چپ‌به‌راست (پیش‌فرض فقط برای مانگا راست‌به‌چپ است)
  - بزرگ‌نمایی با دو انگشت (تا ۴ برابر) و دو بار ضربه، در حالت صفحه‌به‌صفحه
  - شماره‌ی صفحه، لغزنده برای پرش به صفحه، فصل قبلی و بعدی
  - تمام‌صفحه: با یک ضربه نوارها و نوارهای سیستم پنهان یا ظاهر می‌شوند
  - روشنایی: فقط برای همین برنامه و در محدوده‌ی مجاز سیستم؛ با خروج برمی‌گردد
  - خطای بارگذاری تصویر با دکمه‌ی تلاش دوباره و نشانگر بارگذاری
  - کم‌حافظه: فقط صفحه‌های نزدیک بارگذاری می‌شوند و تصویرها با اندازه‌ی صفحه‌ی نمایش دیکد و کش می‌شوند
- **ذخیره‌ی جای مطالعه** برای هر اثر و ادامه‌ی مطالعه از همان صفحه (صفحه‌ی جزئیات، خانه و کتابخانه)
- **علاقه‌مندی‌ها** (قلب در صفحه‌ی جزئیات) و **ادامه‌ی مطالعه** در تب «کتابخانه‌ی من»
- **صفحه‌های نمونه**: همه‌ی فصل‌های Demo صفحه‌ی ساختگی دارند که داخل خود برنامه کشیده می‌شود
- **فصل شخصی از گوشی**: در صفحه‌ی هر اثر «افزودن فصل از عکس‌های گوشی». عکس‌ها به حافظه‌ی خصوصی برنامه کپی می‌شوند، با ترتیب «طبیعی» نام فایل مرتب می‌شوند (۲ قبل از ۱۰) و بعد از بستن برنامه هم می‌مانند. فقط عکس، حداکثر ۳۰۰ صفحه و ۳۰ مگابایت برای هر عکس. فصل شخصی قابل حذف است.
- ذخیره‌سازی محلی با DataStore (تصمیم آگاهانه: برای حجم فعلی داده کافی است و ابزار کامپایل اضافه نمی‌خواهد؛ Room در مرحله‌ی بک‌اند بررسی می‌شود)
- تست‌های واحد برای منطق جست‌وجو، مرتب‌سازی طبیعی، ذخیره‌سازی، ViewModelها و بزرگ‌نمایی

### چه چیزهایی هنوز نیست

حساب کاربری و ورود با پیامک، بک‌اند، پنل مدیریت، امتیاز و دیدگاه، ارسال اثر برای انتشار عمومی، دانلود آفلاین، تصویر جلد واقعی، بزرگ‌نمایی در حالت عمودی، ذخیره‌ی انتخاب حالت و جهت مطالعه (فعلاً فقط تا بستن فصل می‌ماند)، رابط انگلیسی، تست رابط کاربری (androidTest)، امضای نسخه‌ی انتشار.

### نکات

- فصل شخصی فقط روی همین گوشی است و جایی آپلود نمی‌شود. فقط عکس‌هایی را اضافه کن که خودت مالکشی یا اجازه‌ی استفاده داری.
- فصل شخصی با حذف برنامه یا پاک کردن داده‌ی برنامه از بین می‌رود.
- اگر عکس‌ها خیلی بزرگ باشند، اولین بارگذاری هر صفحه کمی طول می‌کشد.

## ساخت APK از روی گوشی

1. محتوای ZIP را (نه خود فایل ZIP را) با «بازکننده» داخل ریپو باز کن. فایل ZIP را با Add file ← Upload files آپلود کن و workflow باز کردن ZIP را اجرا کن.
2. تب **Actions** ← **Build Android APK** ← **Run workflow**. (تغییرهایی که خود Actions کامیت می‌کند، ساخت خودکار را شروع نمی‌کند؛ پس بعد از باز کردن ZIP دستی اجرایش کن.)
3. بعد از تیک سبز، از پایین صفحه‌ی اجرا artifact با نام **Kaminga-debug-apk** را دانلود کن، ZIP را باز کن و `app-debug.apk` را نصب کن (روی نسخه‌ی قبلی هم نصب می‌شود و علاقه‌مندی‌ها حفظ می‌مانند).
4. اگر اجرا قرمز شد: روی مرحله‌ی قرمز بزن و ۳۰–۴۰ خط آخر خطا را بفرست. گزارش تست‌ها در artifact **Kaminga-unit-test-reports** است.

نکته: ورک‌فلو اول تست‌ها را اجرا می‌کند؛ اگر یک تست رد شود، APK ساخته نمی‌شود.

## ساختار

```
app/src/main/java/com/kaminga/reader/
  MainActivity.kt, KamingaApp.kt, KamingaApplication.kt
  navigation/        مسیرها (شامل مطالعه‌گر) و تب‌های پایین
  core/common/       UiState، ساخت ViewModel
  core/designsystem/ کامپوننت‌های مشترک و صفحه‌ی نمونه (DemoPage)
  domain/            مدل‌ها، رابط مخزن‌ها، منطق (جست‌وجو، مرتب‌سازی طبیعی، ادغام فصل شخصی)
  data/demo, data/repository   مخزن نمایشی و داده‌ی Demo
  data/local/        DataStore، کدگذاری ذخیره‌سازی، کپی‌کننده‌ی عکس‌ها
  di/                AppContainer
  feature/           home، search، details، reader، library
  ui/theme/          رنگ و تم
app/src/test/        تست‌های واحد
docs/architecture.md
```

## امنیت و محتوا

هیچ کلید، رمز یا سرویس پولی در پروژه نیست. فقط محتوایی را بخوان یا منتشر کن که مالکش هستی یا مجوز داری. برای ورود با پیامک، بک‌اند و پنل مدیریت، قبل از شروع محدودیت‌های سرویس‌ها (هزینه، کارت بانکی، دسترسی از ایران) جداگانه بررسی می‌شود.
