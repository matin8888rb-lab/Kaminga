# معماری کمینگا (مرحله‌ی ۱)

## لایه‌ها

```
feature/* (Compose + ViewModel)  ->  domain (مدل، ComicRepository، filterAndSort)  <-  data (DemoComicRepository)
```

- `domain` به اندروید وابسته نیست، پس تست‌هایش روی JVM اجرا می‌شود.
- هر صفحه یک ViewModel دارد که `StateFlow<UiState<...>>` می‌دهد: `Loading`، `Success`، `Error(message, retryable)`.
- ViewModelها از `simpleFactory` و `AppContainer` ساخته می‌شوند. این ساده‌ترین راه بدون ابزار اضافه است؛ هیلت عمداً نیامده تا ساخت اولیه کم‌ریسک باشد.

## اتصال به بک‌اند در مرحله‌ی ۳

فقط باید یک پیاده‌سازی دیگر از `ComicRepository` نوشته شود (شبکه + کش محلی) و در `AppContainer` جای `DemoComicRepository` بنشیند. صفحه‌ها و ViewModelها تغییر نمی‌کنند. پرمیشن اینترنت و کتابخانه‌ی تصویر در همان مرحله اضافه می‌شوند.

## جست‌وجو

`normalizeForSearch` متن را یکدست می‌کند (ی/ک عربی، نیم‌فاصله، اعراب، ارقام فارسی). چون داده کم است، فیلتر روی حافظه انجام می‌شود. با زیاد شدن آثار، جست‌وجو باید به سرور منتقل شود (با debounce).

## تصمیم‌ها و محدودیت‌ها

- جهت رابط همیشه راست‌به‌چپ است (نسخه‌ی فارسی‌محور).
- متن‌های رابط فعلاً مستقیم در کد هستند؛ برای انگلیسی باید به `strings.xml` منتقل شوند.
- آیکون‌ها فقط از مجموعه‌ی core هستند (بدون `material-icons-extended`) تا حجم APK و زمان ساخت کم بماند.
